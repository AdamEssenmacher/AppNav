# AppNav

Route-first application navigation for .NET.

AppNav keeps an app's navigation as durable logical state, resolved from typed routes, and leaves the native UI to presenters that can be rebuilt from that state.

> **Status: under construction.** Nothing is published yet. Packages will ship to NuGet.org as `AdamE.AppNav.*`.
