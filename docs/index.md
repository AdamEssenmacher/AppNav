# AppNav documentation

AppNav is under construction, and nothing is published yet. Guides and API documentation arrive with the code they describe.

- [Architecture](architecture.md): the design, the path of one navigation, the layers of the core library, package boundaries and invariants.
- [Navigation state](navigation-state.md): route entries, the leaves of the state, each one occurrence of a route with its metadata and an id.
- [Roadmap](roadmap.md): the order in which the library is being built, and what is done.
- [Routing](routing.md): route templates, how paths are matched against them, which templates are rejected, route metadata, route requests, and how a request is written as a link with its metadata as query values and read back.
